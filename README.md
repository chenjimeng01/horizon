# Horizon (public artifacts)

This repository holds the static files served at
https://chenjimeng01.github.io/horizon/ and nothing else. The source code is
not public.

What is served:

- `index.html` - a landing page
- `preview.html` - the free financial wellness check
- `intake.html` - the client questionnaire
- `sample-report.html` - a specimen report for a fictional household

The planner itself is for adviser use and is not published here. It was served
at `index.html` until October 2026; earlier commits in this repository still
contain that build.

Horizon produces unregulated lifetime cashflow and tax modelling. Nothing
served here is a personal recommendation, a suitability assessment, or advice
on any investment, pension, platform or product.
