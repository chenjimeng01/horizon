# Horizon (compiled build)

This repository holds only the **compiled, single-file build** of Horizon, a
proprietary lifetime cashflow planner, so it can be served on GitHub Pages.

**The source code is not public.** This is the same client-side bundle any
visitor to the live site already downloads in their browser; it is published
here purely as a static hosting artifact.
